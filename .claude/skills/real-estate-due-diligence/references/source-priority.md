# 출처 탐색 원칙과 검색 전략

출처는 고정 목록이 아니다. 조사 목적에 맞는 최적 출처를 스스로 선택한다.
단, 우선순위와 신뢰도 등급은 항상 지킨다.

## 1. 출처 우선순위

### 1순위. 정부/공공기관 원문 (A등급)
필요한 기관만 골라서 확인한다. 전부 훑지 않는다.

| 목적 | 기관/서비스 | 대표 주소 |
|---|---|---|
| 실거래가, 거래량 | 국토교통부 실거래가 공개시스템 | rt.molit.go.kr |
| 서울 부동산 종합 | 서울부동산정보광장 | land.seoul.go.kr |
| 서울 정비사업 단계 | 정비사업 정보몽땅 | cleanup.seoul.go.kr |

주소는 대표값이다. 접속이 안 되거나 개편됐으면 기관명으로 다시 검색해 현재 주소를 확인한다.

### 2순위. 공공 데이터 기반 서비스 (B등급)
공공 데이터를 가공해 보여주는 신뢰도 높은 서비스. 원자료 확인이 어려울 때 활용하되 출처를 명시한다.

### 3순위. 주요 언론 (C등급)
호재/악재의 맥락, 사업 경과 파악용. 기사 본문에서 "확정/계획/검토/추진/전망/추측"을 구분한다.

### 4순위. 민간 부동산 서비스 (D등급)
호갱노노(hogangnono.com), 네이버 부동산(land.naver.com), 아실(asil.kr), 직방, 다방, KB부동산(kbland.kr), 부동산지인(aptgin.com) 등.
적극 참고하되 아래 "민간 서비스 취급 원칙"을 지킨다.

### 5순위. 커뮤니티/블로그/유튜브 (E등급)
사실 확인용으로 쓰지 않는다. 현장 분위기 파악과 "추가로 조사할 키워드 발견" 용도로만 쓴다.
E등급에서 나온 주장은 반드시 A~C등급에서 재확인한 뒤에만 리포트에 올린다.

## 2. 지역에 따라 기관을 동적으로 확장하라

`지역 → 지역 특성 발견 → 관련 기관 추가 발견 → 조사 범위 확장` 방식으로 탐색한다.

예시. "서울 서초구 방배동"이라면:
- 기본: 서울특별시 → 서초구 → 방배동
- 정비사업이 많다 → 정비사업 정보몽땅 + 서초구청 도시계획/정비사업 페이지 + 관련 조합 공고 추가
- 교통 호재가 중요하다 → 국토교통부 고시, 서울시 보도자료, 국가철도공단 추가
- 교육이 중요하다 → 학교알리미, 학구도안내서비스 추가
- 침수 이력이 있다 → 생활안전지도, 서울시 침수흔적도 추가

서울 외 지역이면 서울 전용 서비스(정보몽땅, 열린데이터광장 등)를 해당 지자체의 대응 서비스로 교체한다.

## 3. 검색 전략 (계층화)

단순히 지역명 하나만 검색하고 끝내지 않는다.

### Level 1. 지역 기본정보
`방배동 아파트 실거래가` / `방배동 인구` / `방배동 도시계획` / `방배동 정비사업`

### Level 2. 기관 + 지역 (site: 연산자 활용)
`site:seocho.go.kr 방배동 정비사업` / `site:seoul.go.kr 방배동 도시계획` / `site:cleanup.seoul.go.kr 방배동`

### Level 3. 특정 사업/단지
`방배동 OO아파트 재건축` / `방배동 OO구역 정비사업` / `방배동 OO아파트 실거래` / `방배동 OO아파트 관리비`

### Level 4. 반대 증거 탐색 (필수)
긍정 자료만 찾지 않는다. 최소 1회 이상 수행한다.
`방배동 단점` / `방배동 소음` / `방배동 침수` / `방배동 교통 문제` / `방배동 재건축 문제` / `방배동 아파트 하자` / `방배동 학군 단점`

검색이 끝나면 스스로 물어라. "내가 지금 찾은 정보가 틀렸을 가능성은 무엇인가?"

## 4. 민간 서비스 취급 원칙

- 민간 서비스의 숫자를 그대로 사실로 확정하지 않는다.
- 가능하면 `민간 서비스 → 공식 실거래 → 다른 출처` 순서로 교차검증한다.
- 민간 데이터와 공식 데이터가 다르면: 차이를 발견 → 차이 발생 이유 추정(집계 기간, 평형 기준, 호가 포함 여부) → 가능하면 원자료 확인 → 리포트에 차이를 명시.
- 실거래가(실제 계약), 호가(매도 희망가), 추정가(서비스 알고리즘)를 항상 구분해 적는다.

## 5. 뉴스 취급 원칙

뉴스는 검색 결과를 채우는 용도가 아니다. 호재와 악재를 균형 있게 조사한다.

- 호재 후보: 교통, 개발, 정비사업, 기업 이전, 상업시설, 공원, 학교, 인프라
- 악재 후보: 사업 지연, 주민 갈등, 사업성 문제, 교통 문제, 안전 문제, 개발 무산, 공사 지연, 민원, 규제, 가격 하락
- 기사마다 반드시 구분: `공식 확정 / 계획 / 검토 / 추진 / 업계 전망 / 언론의 추측`
- 기사 제목만 보고 "개발 확정"이라고 판단하지 않는다. 본문과 후속 보도를 확인한다.
- 오래된 기사만으로 현재 상황을 판단하지 않는다. 시간 민감 정보는 최신 보도를 재확인한다.

## 6. 지도 분석 원칙

- 기본 반경 3단계: 500m(도보 생활권), 1km(생활 인프라), 2~3km(상권/업무/교통 영향권)
- 반경은 지역 특성에 따라 조정한다. 산이나 하천이 있으면 지도상 500m라도 실제 접근성이 나쁠 수 있다.
- 원칙: **직선거리 ≠ 실제 생활거리**. 가능하면 실제 도로 기준 동선으로 판단한다.

## 7. 로드뷰/거리뷰 조사 (가용할 때만)

브라우저 도구가 가용해 로드뷰를 실제로 볼 수 있는 경우, 다음을 관찰한다.

- 단지 외부: 단지 입구, 차량/보행자 진입, 경비실, 상가, 주변 도로와 인도, 횡단보도, 버스정류장, 지하철 출입구, 주변 건물/공사, 산/언덕, 전봇대, 주차 상태, 학교, 공원
- 보행 동선: `집 → 지하철`, `집 → 초등학교`, `집 → 마트`, `집 → 주요 상권`을 각각 확인
- 확인한 것만 기록한다. 로드뷰에서 확인할 수 없는 것을 확인했다고 쓰면 안 된다.
- 로드뷰 촬영 시점(연/월)을 함께 기록한다. 오래된 촬영본이면 현재와 다를 수 있음을 명시한다.

로드뷰를 볼 수 없는 환경이면 이 항목들을 리포트의 "현장 확인 항목"으로 돌린다.

## 8. 이미지와 저작권

- 지도/로드뷰 화면을 무단 캡처해 리포트에 재배포하지 않는다.
- 사용 가능한 것: 직접 생성한 SVG 차트, 직접 그린 위치 개념도, 공공누리 등 이용 조건이 확인된 공공 자료, 이용약관상 허용된 자료.
- 실제 지도가 필요하면 지도 서비스 딥링크(검색 URL)를 제공해 사용자가 직접 열게 한다.
- 이미지를 쓰면 반드시 출처를 표기한다. 의사결정에 도움이 되는 이미지만 넣는다.
